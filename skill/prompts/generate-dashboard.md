# Generate Design Intelligence Platform Dashboard

Read `DESIGN.md` first and use the Design System Dashboard pattern.

Include:

- Enterprise Application Shell, Tabs, and Page Container
- Design System Health
- Components Count, Covered Products, AI Generation Count, AI Compliance Rate
- Design Rule Violations, Latest DESIGN.md Version, Last Updated Time
- Token management, Component management, and AI Skill management entries

Use `data-lg` or `data-md` for KPI values and `icons.medium` only for feature entries.
