# Review UI

Read `DESIGN.md`, inspect the target UI, and report only evidence-based findings.

Review in this order:

1. Tokens: colors, typography, radius, shadow, spacing, icon mapping
2. Components: Button, Input, Select, Date Range Picker, Table, Status Tag, Pagination
3. Patterns: Application Shell, Tabs, Page Container, selected page Pattern
4. Governance: Logo protection, creative asset protection, unknown tokens, prohibited behaviors

Output:

- Must-fix violations
- Recommended improvements
- Current compliant items
- The exact DESIGN.md rule behind each finding
